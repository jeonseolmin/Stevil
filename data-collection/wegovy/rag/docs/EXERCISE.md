# 운동 근거 수집·임베딩

운동 추천의 근거를 구축하는 초기 자료 저장소입니다. 현재 플래너의 운동 생성에는 아직 연결하지 않았습니다.

## 저장 구조

- `exercise_sources.json`: 출처 URL, 자료 역할, 대상, 대분류.
- `cache/exercise/sources.sqlite3`: 원본 HTML, SHA-256, 추출 텍스트, 수집 시각, 검토 상태.
- `cache/exercise/embeddings.sqlite3`: 기존 Gemini 768차원 문서 임베딩 캐시.
- 두 DB는 Git에서 제외되므로 다른 PC/서버로 옮길 때 별도로 전달해야 합니다.

```powershell
..\.venv\Scripts\python.exe exercise_store.py --collect
..\.venv\Scripts\python.exe exercise_store.py --build-index
..\.venv\Scripts\python.exe exercise_store.py --query "beginner walking activity"
```

수집과 임베딩은 명시적 명령에서만 수행합니다. 문서 내용·모델·차원 기반 캐시를 재사용하므로 변경 없는 재실행은 새 임베딩을 요청하지 않습니다. 변경된 구간은 새로 임베딩하며 이전 캐시는 보존합니다. 질문 검색은 질문 임베딩 비용이 발생합니다. 이후 답변 생성 연결 시 검색 근거를 모델에 보내는 입력 토큰과 출력 토큰은 계속 발생합니다.

## 2026-09-07 확인

- Compendium 걷기·자전거·컨디셔닝·수중 활동, WHO 개요, EASO 개요: 6개 페이지 수집.
- 79개 구간 최초 임베딩 완료.
- CDC 자동 수집은 HTTP 403으로 차단되어 미수집.
- WHO와 EASO는 지침 전체 본문이 아닌 개요 페이지입니다.

## 추천 연결 전에 남은 작업

1. 지침 본문과 개별 운동 근거 추가 수집, 본문·표 추출 품질 검토. 현재 HTML 텍스트에는 메뉴 등 불필요한 구간이 포함될 수 있습니다.
2. 운동별 구조화 목록: 코드, 한국어명, 다중 유형 태그, 장비, 장소, 난이도, 강도 조건. 컨디셔닝 전체를 근력으로 일괄 분류하지 않습니다.
3. 근거별 적용 대상·주장·제한을 연결하고 검토합니다. MET를 개인별 적합성 또는 실제 소모 열량으로 단정하지 않습니다.
4. 검토된 운동 ID만 추천하도록 플래너를 변경하고 제외 규칙과 출처 표시를 검증합니다.
5. 운영 PostgreSQL 이관은 별도 작업입니다. 이번 저장 대상은 로컬 SQLite이며 기존 RAG DB나 운영 서버는 변경하지 않았습니다.

현재 모든 출처는 `pending`입니다. 수집일을 개정일로 표시하거나 일반 비만 근거를 GLP-1 사용자 전용 근거로 표시하지 않습니다.
