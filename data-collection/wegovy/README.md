# 위고비 RAG 수집 작업 — 2026-09-02

## 현재 상태
이 폴더는 **수집 준비 및 웹 확인 기록**이다. 원본 수집 완료본이나 운영 RAG 데이터셋이 아니다.
- 출처 12개 등록, 검토용 요약 6개 저장.
- 외부 파일 다운로드가 실행 환경의 네트워크 정책으로 차단되었고 권한 요청도 거절됨.
- 원본 PDF/HTML 다운로드 완료: 0개. 모든 항목 ingest_ready=false.
- summary/notes.jsonl은 AI 작성 요약이며 원문으로 인용하거나 자동 임베딩하지 않는다.
- 식약처 URL은 제조사 링크가 연결한 캐시 페이지다. URL의 날짜를 개정일로 단정하지 않는다.
- 국내 최신 허가사항 여부는 미검증이다. 수집일과 개정일을 구분한다.

## 구성
- sources.json: 출처·관할·문서 유형·확인 수준·미완료 상태
- summary/notes.jsonl: 출처 연결된 짧은 검토 메모
- collect.mjs: 네트워크가 허용된 로컬 환경에서 실행할 원본 수집기
- gaps.json: 아직 확보하지 못한 자료
- raw/: 수집기 실행 후 원본 저장. 실행 전에는 비어 있음.
- runs/: 수집 결과, SHA-256, 수집 시각, 최종 URL 기록. 결과는 매번 새 파일로 저장.

## 실행
Node.js 18 이상에서 이 폴더로 이동한 뒤:
```
node collect.mjs --list
node collect.mjs
```
수집기는 공개 URL만 요청하며 CAPTCHA/접근 제한 우회는 하지 않는다.
다운로드 파일은 기본 형식 및 제목 표식을 검사하지만, 내용의 완전성·최신성·표 정확성을 보증하지 않는다.
HTML의 빈 본문이나 로그인 화면 가능성은 사람이 추가 확인한다.
이미 받은 파일을 덮어쓰지 않으며 실행별 폴더에 보존한다.
실행 결과가 성공이어도 ingest_ready는 false다. 검토 후 별도 정제·승인 절차가 필요하다.
sources.json의 original_downloaded는 이번 초기 작업의 상태이며 향후 다운로드 결과는 runs/를 참조한다.

## 원본 확보 후 처리
1. 국가·제품·제형·함량 및 개정일 확인. 미국/유럽 문서는 주사·경구 자료를 절 단위로 분리한다.
2. 국내 함량별 문서의 공통 내용은 중복 정리하되 품목별 차이와 원본 연결을 유지한다.
3. 허가사항의 표·단위·예외·부정 표현을 보존하고 절 및 페이지 기준으로 분할한다.
4. 학회 권고와 품목 허가 기준, 연구 결과를 서로 구분한다.
5. 원문 이용조건을 확인하고 실제 서비스의 원문 재배포 여부를 결정한다.
6. 의료 검토 및 질문별 근거 평가 후 승인된 자료만 검색 인덱스에 넣는다.
